# OTT Streaming Platform

A full-stack OTT streaming platform developed using Django, React, and MySQL. The application provides movie browsing, authentication, watch later functionality, and watch history tracking with a responsive user interface and an admin management system.

---

## Features

### User Features
- User Registration and Login
- Authentication and Authorization
- Browse Movies
- Search Movies
- Watch Later Functionality
- Watch History Tracking
- Responsive UI Design

### Admin Features
- Django Admin Panel
- Add, Edit, Delete Movies
- Manage Users
- Manage Watch History and Watch Later Data

---

## Tech Stack

### Frontend
- React.js
- React Router DOM

- Bootstrap

### Backend
- Django
- Django REST Framework (DRF)

### Database
- MySQL

---

## Project Architecture

- Frontend developed using React
- Backend APIs developed using Django REST Framework
- MySQL used as the relational database
- API communication handled using Axios
- Authentication managed using Django Authentication System
